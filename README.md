Customer Segmentation Using K-Means Clustering on Mall Customer Dataset
K-Means clustering on the Kaggle Mall Customer dataset (200 shoppers) to find five customer segments that support targeted marketing.
Course: CSAC 224 - Machine Learning
School: College of Computer Studies, Camarines Sur Polytechnic Colleges
Authors
Ivy Mullon Doroin
Senbie Abeso Oronan
Jay Marion Ubante
Overview
Traditional rule-based segmentation often misses the complex patterns in real-world customer data. This project uses K-Means, an unsupervised machine learning algorithm, to group mall customers by demographics and spending behavior so businesses can make data-driven marketing decisions.
